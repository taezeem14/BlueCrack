Browser Mode (Selenium WebDriver)

Launches headless Chrome instances that simulate realistic mouse clicks and keyboard typing. Ideal for modern SPA websites with heavy JavaScript, dynamic tokens, and complex event handlers.

HTTP Mode (Hydra-style)

Sends direct asynchronous raw HTTP requests bypassing full browser rendering overhead. Delivers up to 100x higher throughput for REST APIs and standard HTML forms with automatic CSRF token extraction.

Password Spray Mode

Tests a single password against all users before advancing to the next password, evading typical account lockout thresholds.

CUPP Password Profiler

Sequence Generator

Tor & Proxy Anonymity
